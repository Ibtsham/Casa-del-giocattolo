# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

To report a vulnerability or bug, please open a new **Issue** in this repository. It will be reviewed and addressed as soon as possible. 

Please ensure that:
* You avoid spam messages.
* The issue is not caused by device incompatibility.

---

> **Note on Google Play Protect Warning**:  
> Since the app APK is built directly from source and distributed via GitHub (not Google Play Store), Play Protect may display a warning upon installation. This is standard for custom APKs. You can safely proceed by tapping the **arrow down button** and selecting **"Install anyway"**.
