# Linee Guida per i Contributi

Grazie per l'interesse per **Casa del Giocattolo**!

## Come contribuire

Al momento questo progetto è gestito esclusivamente dallo sviluppatore principale. 

* **Suggerimenti e Segnalazioni**: Se hai idee per nuove funzionalità o trovi dei bug, ti invitiamo ad aprire una **Issue** nella sezione dedicata di GitHub.
* **Pull Request**: Non si accettano modifiche dirette al codice sorgente via Pull Request senza previo accordo nelle Issues.

Apprezziamo ogni feedback e suggerimento per migliorare l'applicazione!
